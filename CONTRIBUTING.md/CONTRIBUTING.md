# Contributing to OSINT Center

Thank you for considering contributing to OSINT Center! This project is an Open Source Intelligence (OSINT) command center application.

## Getting Started

1. Fork the repository
2. Clone your fork: `git clone https://github.com/agiprogrammerch/osint-center.git`
3. Create a new branch: `git checkout -b feature/your-feature-name`
4. Make your changes
5. Commit your changes: `git commit -m "Add: description of changes"`
6. Push to your fork: `git push origin feature/your-feature-name`
7. Open a Pull Request against the `main` branch

## Development Setup

- Python 3.x required
- Install dependencies: `pip install -r requirements.txt` (if applicable)
- Run the server: `python serve.py`
- Open `index.html` in your browser

## Code Style

- Follow PEP 8 for Python code
- Use meaningful variable and function names
- Add comments for complex logic
- Keep functions small and focused

## Pull Request Process

1. Ensure your code passes linting checks
2. Update the README.md if you change functionality
3. The CI/CD pipeline will run automatically on your PR
4. All checks must pass before merging
5. A maintainer will review your PR and provide feedback

## Reporting Issues

- Use the Issues tab to report bugs or suggest features
- Provide detailed steps to reproduce issues
- Include browser and OS information if relevant

## Security

For security vulnerabilities, please email agiprogrammer@gmail.com directly instead of opening a public issue. See SECURITY.md for details.
